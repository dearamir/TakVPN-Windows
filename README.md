# TakVPN for Windows

Independent Windows 10/11 x64 desktop client for TakVPN.

## Features
- Persian RTL WPF interface
- Import and local storage for VLESS, VMess and Trojan links
- Xray-core process integration and Wintun TUN support
- Proxy latency tests through a local Xray SOCKS inbound
- Self-contained Windows installer and portable ZIP generated by GitHub Actions

## Build
Requires .NET 8 SDK on Windows:

```powershell
dotnet publish .\TakVPN.Windows\TakVPN.Windows.csproj -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true
```

The workflow downloads the official Xray Windows x64 archive, bundles Xray and Wintun, smoke-tests the Xray binary, and publishes a separate Windows release. Windows builds and releases are independent of the Android repository.

## Status
This is an early integration and has not yet been validated on a physical Windows machine. Test VPN routing, administrator elevation, IPv4/IPv6, Wintun lifecycle, sleep/resume, and supported transports before production use. The installer is not digitally signed.
